📖 Hướng dẫn cài nhanh

  1. Trên điện thoại Android: Tải file MULucDia_PKAuto.apk ở nút màu xanh lá, mở file để cài đặt (cho phép Cài ứng dụng không rõ nguồn gốc nếu máy hỏi). Vào game mở tab KEY bấm Copy Mã Máy gửi Zalo để kích hoạt.
  2. Trên giả lập LDPlayer (PC): Tải PKAuto_APK.zip, giải nén rồi mở PKAuto_APK.exe (nếu Windows Defender cảnh báo, chọn More info -> Run anyway hoặc thêm ngoại lệ thư mục).
  3. Cập nhật bản mới: Điện thoại tự tải bản mới ngay trong game (tab KEY -> Kiểm Tra); giả lập bấm nút 🚀 Cập Nhật trên tool.
